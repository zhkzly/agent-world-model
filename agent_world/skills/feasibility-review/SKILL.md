# Feasibility Review

Review whether accepted upstream artifacts are ready for implementation.

Rules:

- Identify semantic risks, missing evidence, weak tasks, verifier gaps, and tool-surface inconsistencies.
- Provide advisory status: pass, fail, or needs_human.
- Suggest a repair stage when a risk is actionable.
- Do not decide release acceptance.
- Do not waive framework gates.

Accepted output target: advisory feasibility review JSON only.
